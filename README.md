## How to use this repo

1. Read a section and write only the ideas you want to remember in its note.
2. Use the equations and trade-offs sections for things you expect to revisit.
3. Turn unanswered questions into review questions when you find an answer.
4. Put small code experiments in `experiments/` and link them from the relevant chapter note.
